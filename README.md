# ¡Esa princesa es MÍA!

Un plataformas de monigotes lleno de trampas. Eres un malvado que quiere secuestrar a la Princesa Petunia... pero el Conde Cuernos se te ha adelantado. Supera 10 niveles para rescatarla y secuestrarla tú.

**Juega aquí:** https://hersadev.github.io/esa-princesa-es-mia/

## Controles

- **← →** moverse
- **ESPACIO** saltar (mantén para saltar más alto)
- **R** reiniciar nivel · **ESC** pausa · **M** sonido

Reta a tus amigos: gana quien termine con menos muertes.
